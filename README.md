# Python OOP Banking System 🏦

A secure and clean Bank Management System built using **Object-Oriented Programming (OOP)** principles in Python. This project simulates essential real-world banking functionalities.

## ✨ Features
*   **Account Management:** Create and manage user bank accounts.
*   **Secure Transactions:** Safe money deposit and withdrawal features.
*   **Balance Check:** Quick and real-time account balance inquiries.
*   **Transaction History:** Keeps a log of all previous actions.

## 🛠️ OOP Concepts Used
*   **Classes & Objects:** Modeled real bank structures using `Bank`, `Account`, and `User` classes.
*   **Encapsulation:** Hidden sensitive data (like account balance) using private variables (`__balance`).
*   **Inheritance:** Created base classes to extend features cleanly.

## 🚀 How to Run
1. Clone this repository to your computer.
2. Open your terminal and run:
   ```bash
   python main.py
   ```
