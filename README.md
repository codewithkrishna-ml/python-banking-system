## 📝 Combined Projects Overview

This repository features a unified structure that integrates three distinct, functional modules built completely from scratch:

### 1. Bank Account Management System 🏦
A secured banking simulation module designed to handle robust financial operations.
*   **Key Features:** Secure account creation, balance maintenance, real-time deposits, and error-free withdrawal logics.
*   **OOP Focus:** Demonstrates **Encapsulation** by keeping sensitive data (like balances) private and updating them via secure methods.

### 2. EduTrack-OOP (Student Performance & Attendance Tracker) 📊
An automated evaluation system that tracks academic records and highlights student standings.
*   **Key Features:** Tracks academic grades, calculates performance averages, and monitors attendance percentages.
*   **Logical Logic:** Uses strict conditional metrics to automatically flag profiles requiring improvement (e.g., attendance below 75% or scores below 50%).

### 3. School Library Management System 📚
A structured database simulator designed to manage book tracking and inventory logistics.
*   **Key Features:** Handles real-time borrowing and returning workflows, and maintains precise library catalog displays using optimized class relationships.
